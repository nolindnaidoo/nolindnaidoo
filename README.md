### [The `*-le` suite](https://github.com/nolindnaidoo?tab=repositories&q=-le)

Ten zero-hassle developer utilities:

- [envsync-le](https://github.com/nolindnaidoo/envsync-le) — detect,
  compare, and synchronize `.env` files with visual diff and conflict
  resolution
- [secrets-le](https://github.com/nolindnaidoo/secrets-le) — detect and
  sanitize credentials, tokens, and API keys locally, before you commit
- [regex-le](https://github.com/nolindnaidoo/regex-le) — test and
  validate regular expressions with live previews and ReDoS detection
- [scrape-le](https://github.com/nolindnaidoo/scrape-le) — check page
  reachability and anti-scraping measures before deploying scrapers
- [strings-le](https://github.com/nolindnaidoo/strings-le) — extract
  and analyze strings from JSON, YAML, CSV, TOML, INI, and ENV
- [numbers-le](https://github.com/nolindnaidoo/numbers-le) — numeric
  extraction with statistical analysis and validation
- [dates-le](https://github.com/nolindnaidoo/dates-le) — dates and
  timestamps with smart validation
- [paths-le](https://github.com/nolindnaidoo/paths-le) — file-path
  extraction, validation, and cross-OS analysis
- [urls-le](https://github.com/nolindnaidoo/urls-le) — URL extraction
  and link validation across logs, configs, and code
- [colors-le](https://github.com/nolindnaidoo/colors-le) — color
  extraction and palette analysis from CSS, HTML, and JavaScript
